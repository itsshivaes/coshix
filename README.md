## ✨ Overview
Welcome to the official source code repository for **[coshix.in](https://coshix.in)**. 

This repository is the live engine behind the website, seamlessly deployed via GitHub Pages. Built with the Astro framework, this project serves as a masterclass in achieving peak web performance organically. There are no heavy JS or CSS minification scripts masking poor architecture here—just pure, clean code that delivers a lightning-fast, accessible, and highly optimized user experience.

## 🌟 Key Features
- **🌐 Live on GitHub Pages:** Automated deployment pipeline running directly through GitHub Actions.
- **⚡ Native Speed:** Achieves 90+ PageSpeed scores naturally through clean Astro architecture, entirely bypassing the need for forced CSS/JS minification.
- **📈 Flawless SEO & Accessibility:** Pre-configured with robust schema markup, perfect contrast ratios, and keyboard-friendly navigation.
- **📝 Sveltia CMS Integrated:** Content is managed effortlessly through a lightweight, Git-based Sveltia CMS configuration built directly into the admin dashboard.
- **🎨 Tailwind Powered:** Features a highly customizable design system using custom Tailwind plugins for grid and theme management.
- **🔍 Built-in Search & Rich Content:** Includes a dedicated search modal, dynamic post filtering, and rich MDX shortcodes (Accordions, Tabs, YouTube embeds).

## 💻 Tech Stack
- **Framework:** [Astro](https://astro.build/)[cite: 2]
- **Styling:** Tailwind CSS
- **Content Management:** Sveltia CMS
- **Package Manager:** pnpm
- **Scripting:** TypeScript & TSX
